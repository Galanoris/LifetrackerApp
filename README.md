# Good Life Tracker

A personal check-in app for iPhone, installed from Safari to the Home Screen. All data stays on the phone (IndexedDB). There's no account, no backend and no analytics. See [good-life-tracker-app-plan.md](good-life-tracker-app-plan.md) for the full plan.

## Develop

```sh
npm install
npm run dev              # http://localhost:5173
npm run dev -- --host    # reachable from the iPhone on the same Wi-Fi (layout checks only)
npm test                 # unit tests (dates, storage, backup, stats)
npm run build            # type-check + production build into dist/
```

Dev only: open `http://localhost:5173/?demo` to load a **separate** database filled with about 10 weeks of fake answers, so you can try Insights.

Add `#week`, `#insights` or `#settings` to the URL to open a tab directly.

## Deploy (GitHub Pages)

1. Create a GitHub repo and push this folder to `main`.
2. In the repo, go to **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Every push to `main` runs the tests, builds and deploys. The workflow sets the base path to `/<repo-name>/`.

## Install on the iPhone

1. Open the Pages URL **in Safari**.
2. Tap **Share → Add to Home Screen → Add**.
3. Always open the app from the Home Screen icon. Data in a Safari tab is stored separately and can be evicted.
4. When a new version is deployed, the app shows "A new version is available → Reload". Your data isn't affected.

## Backups

Go to Settings → **Export backup (JSON)** → Save to Files → iCloud Drive / "Good Life Tracker Backups". The Today screen reminds you when the last backup is more than 7 days old. To restore, use Settings → **Restore backup…**, which replaces all data on the device.

**Export CSV** produces the spreadsheet's wide layout (one column per day, then a weekly section) for Excel.

## Code map

| Path | What |
|---|---|
| `src/lib/types.ts` | Data model (Dimension, Entry, DayNote, WeekNote, Settings) |
| `src/lib/seed.ts` | v1 question set (18 daily and 6 weekly), used on first run only |
| `src/lib/db.ts` | Dexie database, schema versions, save helpers, backup/restore |
| `src/lib/dates.ts` | Local dates, ISO weeks, morning-mode cutoff, weekly due logic |
| `src/lib/stats.ts` | Rolling averages, category scores, streaks, comparisons, CSV |
| `src/screens/*` | Today, Week, Insights, Settings, question editor |

**Changing the database structure:** add `this.version(2).stores({...}).upgrade(...)` in `db.ts`. Never edit version 1. Bump `SCHEMA_VERSION`.

The questions are data. Edit them in the app (Settings), not in `seed.ts`. The seed only runs on a fresh install.

Icons are generated by `npm run icons` (`scripts/gen-icons.mjs`).
